# 결정

- 오래된 강의 내용을 그대로 재현하지 않고 현재 Living Standard에 맞는 학습 노트로 보정했다.
- 단정적인 호환성 설명 대신 표준이 보장하는 의미와 실무 권장 사항을 구분했다.
- `/path`를 완전한 절대 URL이 아닌 기반 URL을 필요로 하는 상대 URL로 분류했다.
- 이미지의 `width`·`height`는 제거 대상이 아니라 고유 비율 예약에 유용하다고 설명하고, 반응형 표시 크기는 CSS가 담당하도록 구분했다.
- `<frame>`·`<frameset>`은 역사적 설명만 남기고 새 문서에서 사용하지 않도록 했다.
- 사용자 산출물 안에 WHATWG 공식 표준 링크를 직접 제공했다.
