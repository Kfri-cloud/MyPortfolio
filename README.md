# 김정현 포트폴리오

3D 모델링, 메타버스, Unity 작업을 소개하는 웹사이트입니다. HTML, CSS, JavaScript로 만들었습니다.

바로 보기: [김정현 포트폴리오 웹사이트](https://kfri-cloud.github.io/MyPortfolio/)

## 프로젝트 보기

- [메타버스 작업](https://www.youtube.com/playlist?list=PLAPu8wiIomjE)
- [Unity 작업](https://www.youtube.com/playlist?list=PLRB0P_81BRHY)

## 사이트에서 할 수 있는 일

- 화면이 좁아지면 글과 이미지 배치가 휴대전화 크기에 맞게 바뀝니다.
- 프로젝트 캐릭터에 마우스를 올리면 여러 장의 이미지가 차례로 바뀝니다. 캐릭터나 `프로젝트 보기` 버튼을 누르면 해당 작업을 볼 수 있습니다.
- 작은 화면에서는 햄버거 메뉴로 소개, 기술, 프로젝트, 연락처로 이동할 수 있습니다. 화면 옆의 영역 이동 버튼은 작은 화면에서 숨깁니다.
- 위로 스크롤하면 상단바가 나타나고, 아래로 스크롤하면 숨겨집니다. 맨 위로 가기 버튼도 있습니다.
- 다크모드 버튼을 누르면 밝은 화면과 어두운 화면을 바꿀 수 있습니다. 선택한 모드는 새로고침해도 유지됩니다.
- 연락처 입력란은 빈칸과 잘못된 이메일 형식을 확인하고 오류를 보여줍니다. 현재 실제 메시지 전송 기능은 연결되어 있지 않습니다.

## 어떻게 만들었나요?

| 파일 | 맡은 일 |
| --- | --- |
| `Script/main Script_test/index.html` | 글, 이미지, 버튼 등 페이지 내용과 구조 |
| `css/style.css` | 색, 크기, 배치, 휴대전화 화면에 맞는 모양 |
| `js/main.js` | 메뉴, 스크롤, 프로젝트 이미지, 입력값 확인 등의 동작 |
| `js/theme.js` | 다크모드 버튼과 선택한 모드 저장 |

파일을 나눈 이유는 글을 고칠 때는 HTML, 모양을 바꿀 때는 CSS, 버튼 동작을 바꿀 때는 JavaScript를 찾기 쉽게 하기 위해서입니다.

`header`, `nav`, `main`, `section`, `footer` 같은 태그는 각각 상단, 이동 메뉴, 중심 내용, 내용의 묶음, 하단을 뜻합니다. 이름이 있는 태그를 쓰면 페이지 구조를 이해하기 쉽습니다.

색은 CSS 파일의 `:root`에 모아 두었습니다. 예를 들어 노란색을 바꾸고 싶을 때 여러 곳을 찾아 고치지 않아도 됩니다.

버튼을 누르는 동작은 HTML에 직접 쓰지 않고 JavaScript의 `addEventListener`로 연결했습니다. 페이지 내용과 버튼 동작을 따로 관리하기 쉽습니다.

## 버튼을 누르면 어떻게 되나요?

```text
버튼 클릭 → 현재 값 변경 → 화면에 변경 내용 표시
```

다크모드 버튼을 예로 들면, 클릭했을 때 밝은 모드인지 확인하고 반대 모드로 바꿉니다. 바뀐 값을 저장한 다음, CSS가 새 색으로 화면을 보여줍니다.

프로젝트 이미지도 비슷합니다. 마우스를 올리면 일정한 간격으로 다음 사진을 보여주고, 마우스를 떼면 첫 번째 사진으로 돌아갑니다.

## GitHub 저장소 목록을 가져오는 코드

`js/main.js`에는 GitHub에서 저장소 목록을 요청하는 코드가 있습니다. 요청 중에는 “로딩 중”, 성공하면 저장소 카드, 목록이 비어 있으면 안내 문구, 실패하면 오류와 다시 시도 버튼을 보여주도록 작성했습니다.

요청할 때는 `fetch`를 사용합니다. `async/await`는 응답을 기다리는 데, `try/catch`는 실패했을 때 오류 화면을 보여주는 데 사용합니다. `map`은 받은 저장소 목록을 카드 내용으로 바꾸는 데 사용합니다.

현재 웹페이지에서는 예전 GitHub 저장소 목록 영역을 CSS로 숨겨 두었습니다. 따라서 이 코드는 파일에 있지만, 방문자 화면에는 목록이 보이지 않습니다. 대신 모델링·메타버스·Unity 작업 링크가 표시됩니다.

## 화면 배치

`Flexbox`는 메뉴나 프로젝트 설명처럼 한 줄 또는 한 방향으로 놓을 때 사용했습니다. `Grid`는 스킬 이미지처럼 여러 칸에 나누어 놓을 때 사용했습니다. 작은 화면을 기본으로 두고, 화면이 커지면 배치를 넓히도록 작성했습니다.

## 실행 방법

저장소를 내려받은 뒤 `Script/main Script_test/index.html`을 브라우저에서 열면 됩니다.

```bash
git clone https://github.com/Kfri-cloud/MyPortfolio.git
```

## 확인할 점

- 화면 너비를 줄였을 때 글과 이미지가 잘리는지 확인합니다.
- 다크모드를 바꾼 뒤 새로고침해도 선택이 유지되는지 확인합니다.
- 휴대전화 화면에서 햄버거 메뉴와 영역 이동이 되는지 확인합니다.
- 프로젝트 이미지와 버튼이 올바른 링크로 열리는지 확인합니다.
- 연락처에 빈칸이나 잘못된 이메일을 넣었을 때 오류가 표시되는지 확인합니다.

웹사이트는 GitHub Pages로 공개되어 있습니다. 사이트 파일은 `docs/` 폴더에 있으며, 내용을 수정한 뒤에는 `scripts/build-pages.ps1`을 실행해 배포용 파일을 갱신할 수 있습니다.
